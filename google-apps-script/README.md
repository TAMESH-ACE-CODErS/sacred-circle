# CommunityQuotes — free Google Sheet backend

No paid API, no database, no visitor sign-in. Visitors read published rows and post one row; admins edit, hide and delete rows from `/admin`.

## 1. Create the Sheet

1. Make a Google Sheet (any name).
2. Open **Extensions → Apps Script** and paste `Code.gs` into `Code.gs`, replacing its contents.
3. Save. The script creates the tab `CommunityQuotes` and these headers on first run:

   `id | timestamp | author_name | category | content | status`

   - `id` — UUID
   - `timestamp` — ISO date string
   - `author_name` — visitor name, or `Guest`
   - `category` — `quote`, `opinion` or `reflection`
   - `content` — the shared text
   - `status` — `published` or `hidden`

## 2. Set the admin secret

In Apps Script: **Project Settings → Script Properties → Add script property**

- Property: `QUOTES_ADMIN_KEY`
- Value: a long random string (for example, generated by a password manager)

Never put this key in a `VITE_` variable or in the frontend bundle. The `/admin` page asks for it at runtime and keeps it only in the current browser tab. The serverless bridge forwards it to Apps Script for verification.

## 3. Deploy the web app

1. **Deploy → New deployment → Web app**
2. Execute as: **Me**
3. Who has access: **Anyone**
4. Copy the `/exec` URL.

## 4. Connect the site

Copy `.env.example` to `.env.local` and set:

```
VITE_QUOTES_SCRIPT_URL=https://script.google.com/macros/s/YOUR_ID/exec
```

Restart `npm run dev`. For Vercel, add the same variable in **Project Settings → Environment Variables**; `api/quotes.ts` reads it server-side, so the browser never makes a cross-origin call and no CORS setup is needed.

## Endpoints (proxied at `/api/quotes`)

| Call | Action |
| --- | --- |
| `GET ?action=list` | Published rows, newest first |
| `GET ?action=list_all&adminKey=…` | All rows for `/admin` |
| `POST { action: "create", author_name, category, content }` | Public post |
| `POST { action: "update", adminKey, id, author_name, category, content, status }` | Admin edit / hide |
| `POST { action: "delete", adminKey, id }` | Admin delete |

If `VITE_QUOTES_SCRIPT_URL` is missing, the site degrades gracefully: the public section shows a setup note instead of a broken feed.
